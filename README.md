| 項目 | 内容 |
|------|------|
| Database URL | https://lres-schedule-default-rtdb.asia-southeast1.firebasedatabase.app |
| データパス | `eikaiwa_data` |
| データ構造 | `eikaiwa_data > D`（時間割データ）, `MK`（振替データ）, `_saved`（保存日時） |
| DBルール | `.read: true / .write: true`（認証なし・公開アクセス） |
| Auth | **なし**（v37で完全除去） |

### DBルールについて
認証を除去したためURLを知っていれば誰でも読み書き可能。ただし教室の時間割データのみで個人情報は最小限。プログラム自体はGitHubで管理されているため書き換え不可。Firebaseから警告メールが届いた場合はDBルールを適宜調整する。

### 生徒名の制約（重要）
Firebaseのキーに使えない文字が生徒名に含まれると保存エラーになる。
**生徒名に使ってはいけない文字：`. # $ / [ ]`**
ハイフン `-` やアンダースコア `_` は使用可能。備考欄など生徒名以外は制約なし。

## 確定済み仕様（変更してはいけないこと）

- 生徒の追加・削除・休会・復帰はすべて「現在表示中の週の対象授業日」を起点にする
- クラスの追加・属性変更（レベル・時間・色等）も「現在表示中の週」以降にのみ反映
- 休校 → 振替先を次の有効日へスライド
- 臨時休校 → スライドしない、コマごとグレーアウト・振替チップも一緒に非表示
- 振替不可日 → 元クラスは赤背景・グレー文字・打ち消し線、振替不可日のコマにグレー文字・打ち消し線で消滅表示
- 生徒チップの行間：`line-height:1.05`・`margin`上下0
- 確定済みの週は全操作ブロック（「確定を解除」ボタンのみ有効）
- 名前変更はクラス単位（他クラスの同名生徒に影響しない）

## アプリの機能概要

### 時間割タブ
- 火〜土曜の週間時間割をグリッド表示
- クラスブロックをタップ → **週別詳細モーダル**が開く
  - 生徒ごとに 出席 / 欠席↺（振替あり）/ 欠席✗（振替なし）/ 遅刻 をインライン操作
  - ✉️（封筒）/ 💰（お金）フラグをトグル（オン時はチップの名前が赤表示）
  - 📝 備考ボタンで入力欄展開（入力時も名前が赤表示）
  - 振替参加者は「振替参加」セクションに別表示
  - プライベートクラスは候補生徒リストから選択（選択即「出席」設定）
  - ⚙ クラス設定ボタンで管理タブの当該クラスへ移動
- 週の移動：「前週」「次週」ボタン、またはスマホで左右スワイプ
- ロゴ（LRES）タップ → 今週の時間割に戻る
- 「この週を確定」ボタンで週を確定（解除可）
- **確定済みの週は全操作が無効**
- 過去3ヶ月より前には遡れない（ボタン・スワイプともに制限）
- スポット授業はオレンジ枠線で表示

### 休校・面談タブ
- 休校日の設定（振替あり生徒は翌週以降へスライド）
- 臨時休校の設定（振替はスライドしない）
- 振替不可日の設定（パーティー等）
- 面談の追加
- **確定済みの週は操作不可**

### 管理タブ
- クラスの追加（見出し横のボタン）・編集・削除
- プライベート生徒候補リストの管理（名前変更・削除）
- 生徒の追加・削除・休会・復帰・名前変更（クラス単位）
- **確定済みの週は操作不可**

### 過去週の保護（2層構造）
| 要素 | 確定済み週 | 未確定の過去週 |
|------|-----------|-------------|
| クラスの存在 | ✅ スナップショット | ✅ `joinDate`/`leaveDate` |
| 生徒メンバー | ✅ スナップショット | ✅ 生徒ごとの `joinDate`/`leaveDate` |
| レベル・時間・色・テキスト | ✅ スナップショット | ✅ `attrLog` 履歴 |

### 自動データ整理（起動時）
3ヶ月より古いデータを自動削除：
- スナップショット（`D.snapshots`）
- 出席記録（`D.att`）
- フラグ記録（`D.flags`）
- 振替記録（`MK`）
- クラス属性履歴（`attrLog`）— ただし直前の値は1件残す

### Firebase連携
- 右上のステータス表示：🟢接続中 / 🔵同期中 / 🟡オフライン / ⚪未接続
- 「🔄 更新」ボタンでFirebaseから最新データを取得
- データ変更時は自動でFirebaseへ保存（💾ボタンで手動保存も可）
- Firebase設定はステータス表示をクリックして開くモーダルから入力

## 重要な変数

| 変数 | 内容 |
|------|------|
| `D` | すべての時間割データ（クラス・生徒・出席・休校等） |
| `D.att` | 出席記録 `{cid\|date\|name: status}` |
| `D.flags` | 封筒・お金フラグ `{cid\|date\|name: {give, recv}}` |
| `D.priSel` | プライベートクラスの週ごと生徒選択 `{cid\|weekKey: 生徒名}` |
| `D.snapshots` | 確定済み週のクラス構成スナップショット `{weekKey: classes[]}` |
| `MK` | 振替データの配列 `{id, fromCid, fromDate, student, toCid, toDate, status?, ...}` |
| `ws` | 現在表示中の週の月曜日（Dateオブジェクト） |
| `PPM` | グリッドの1分あたりのピクセル数 |
| `_viewClasses` | 表示中の週のクラス構成（確定済み過去週はスナップショット、それ以外は `D.classes`） |

### `D.classes` の各クラスオブジェクト
```
{
  id, dow, start, end, level, color, textbook,
  subCid,          // 振替先クラスID
  kids, isPrivate, // キッズ / プライベートフラグ
  students: [],    // 生徒名配列
  sd: {            // 生徒ごとの補足データ
    [name]: { note, leaveHistory, joinDate, bg, bn, ... }
  },
  joinDate,        // このクラスが有効になる日付（YYYY-MM-DD）
  leaveDate,       // このクラスが終了する日付
  attrLog: [       // 属性変更履歴
    { from, start, end, level, color, textbook }
  ]
}
```

## 重要な関数

| 関数 | 内容 |
|------|------|
| `getClsAttr(cls, ds, field)` | 指定日付時点でのクラス属性値を返す（`attrLog` 参照） |
| `getA(cid, ds, n)` | 出席記録を返す（デフォルト `'present'`） |
| `setA(cid, ds, n, v)` | 出席記録を設定 |
| `getFlags(cid, ds, n)` | 封筒・お金フラグを返す |
| `registerMK(fromCid, fromDate, student)` | 振替を登録（次の有効日を自動検索） |
| `removeMK(cid, ds, name)` | 振替を削除 |
| `getMKfor(toCid, toDate)` | 指定クラス・日付への振替参加者を返す |
| `isConfirmed()` | 現在の週が確定済みか |
| `getPriStudent(cid)` | 現在週のプライベートクラス選択生徒名 |
| `isMemberOn(cls, name, ds)` | 指定日付に生徒がメンバーかどうか |
| `isOnLeave(cls, name, ds)` | 指定日付に生徒が休会中かどうか |
| `dayClasses(dow, ds)` | 指定曜日・日付のクラス一覧（`joinDate`/`leaveDate` フィルタ済み） |
| `pruneOldSnapshots()` | 3ヶ月より古いデータを全種類削除 |
