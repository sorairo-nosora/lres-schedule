### DBルールについて
認証を除去したためURLを知っていれば誰でも読み書き可能。ただし教室の時間割データのみで個人情報は最小限。プログラム自体はGitHubで管理されているため書き換え不可。Firebaseから警告メールが届いた場合はDBルールを適宜調整する。

## 確定済み仕様（変更してはいけないこと）

- 生徒の追加・削除・休会・復帰はすべて「現在表示中の週の対象授業日」を起点にする
- 休校 → 振替先を次の有効日へスライド
- 臨時休校 → スライドしない、コマごとグレーアウト・振替チップも一緒に非表示
- 振替不可日 → 元クラスは赤背景・グレー文字・打ち消し線、振替不可日のコマにグレー文字・打ち消し線で消滅表示
- 生徒チップの行間：`line-height:1.05`・`margin`上下0

## アプリの機能概要

### 時間割タブ
- 火〜土曜の週間時間割をグリッド表示
- 生徒チップをタップ → 出席 / 欠席（振替あり）/ 欠席（振替なし）/ 遅刻 を記録
- 欠席（振替あり）を選ぶと振替チップが自動で振替先クラスに表示される
- 週の移動：「前週」「次週」ボタン、またはスマホで左右スワイプ
- 「この週を確定」ボタンで週を確定状態にできる
- 初期表示：今週（日曜日の場合は翌週）

### 休校・面談タブ
- 休校日の設定（振替あり生徒は翌週以降へスライド）
- 臨時休校の設定（振替はスライドしない）
- 振替不可日の設定（パーティー等）
- 面談の追加

### 管理タブ
- クラスの追加・編集・削除
- プライベート生徒候補リストの管理

### Firebase連携
- 右上のステータス表示：🟢接続中 / 🔵同期中 / 🟡オフライン / ⚪未接続
- 「🔄 更新」ボタンでFirebaseから最新データを取得
- データ変更時は800ms後に自動でFirebaseへ保存
- Firebase設定はステータス表示をクリックして開くモーダルから入力

## コード構成（index.html内）

| 行番号目安 | 内容 |
|-----------|------|
| 1〜140 | CSS（スタイル定義・印刷用メディアクエリ含む） |
| 141〜300 | HTML構造（ヘッダー・タブ・時間割グリッド・モーダル類） |
| 300〜510 | JS基本関数（日付処理・振替ロジック・`registerMK`等） |
| 510〜720 | `render()` 関数（時間割グリッドの描画） |
| 720〜1100 | UI操作関数（出席記録・休校・管理タブ等） |
| 1100〜1260 | 管理タブ描画・生徒追加削除等 |
| 1260〜1350 | Firebase設定UI・`initFirebase()`・`fbPullData()`・`fbPush()` |
| 1350〜1400 | データ保存・読込（`save()` / `load()` / `applyLoadedData()`） |
| 1400〜末尾 | 印刷・初期化・スワイプ処理 |

### 重要な変数
- `D` : すべての時間割データ（クラス・生徒・出席・休校等）
- `MK` : 振替データの配列
- `ws` : 現在表示中の週の月曜日（Dateオブジェクト）
- `PPM` : グリッドの1分あたりのピクセル数
- `_printMode` : 印刷中フラグ（`render()`がPPMを上書きしないようにする）
